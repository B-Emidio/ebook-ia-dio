# Título
```
Crie algumas sugestões de título para um e-book com tema de Design Patterns para a área de programação, com referências ao filme Matrix. O título deve ser no formato <TÍTULO>: <SUBTÍTULO>, com ambos <TÍTULO> e <SUBTÍTULO> sendo substituídos por uma frase curta e impactante.
```

# Roteiro

```
Crie o texto conteúdo para um e-book com foco em Design Patterns, com caráter introdutório ao assunto, listando os diferentes tipos existentes e mostrando exemplos práticos de cada um.

{REGRAS}
* O conteúdo deve ser dividido em seções maiores, indicando os tipos principais
* Fazer uma breve introdução do que é um design pattern e por que utilizá-los
* Dentro de cada seção, deve ser listado os 3 principais exemplos de design pattern daquele tipo
* Utilize textos curtos para as explicações, contendo a explicação do padrão, para que serve e como funciona em um pequeno parágrafo sem tópicos
* Escolha exemplos de design patterns mais fáceis de serem explicados, que não exijam códigos complexos e longos
* Mostre exemplos reais de código para cada tópico
```
