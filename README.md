# Criando um Ebook com ChatGPT & Ideogram

Projeto para testar o funcionamento de ferramentas de IA de diferentes mídias. Foram utilizadas diferentes técnicas de prompts para auxiliar na criação textual e visual de um e-book informativo de tecnologia.

### Ferramentas Utilizadas

* [![ChatGPT][ChatGPT]][ChatGPT.com]
* [![Ideogram][Ideogram]][Ideogram.com]

### Como foi utilizado

* Geração de sugestões temáticas com `ChatGPT`
* Baseado nas sugestões, geração de títulos para o e-book com tema de Matrix
* Desenvolvimento de conteúdo informativo e trechos de código com novos prompts e regras no `ChatGPT`
* Criação de imagem para capa seguindo a temática com `Ideogram`, testando diferentes estilos e características de imagem
* Desenvolvimento do e-book utilizando o `Powerpoint`, aplicando diferentes técnicas de layout

### Como executar

* Utilizar os prompts em `prompts/conteudo` no `ChatGPT`
* Gere a imagem de capa para o e-book com o prompt em `prompts/capa` com o `Ideogram`
* Utilizando ferramentas de edição de texto, monte o e-book com o conteúdo textual e visual criado
